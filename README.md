# Retail Sales Analysis

## Project Overview
Retail Sales Analysis is a data analytics project designed to analyze retail sales data and identify meaningful business insights. The project focuses on understanding sales performance, profitability, customer segments, product categories, regional performance, and discount impact.

The analysis uses Python, SQL, and Power BI to transform raw sales data into meaningful insights and interactive visualizations.

## Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and subcategories.
- Compare sales across different regions.
- Understand customer segment performance.
- Analyze the impact of discounts on profitability.
- Build an interactive Power BI dashboard to support business decision-making.

## Project Workflow

1. **Data Collection:** Obtained the retail sales dataset.
2. **Data Preparation:** Inspected and prepared the data using Python and Pandas.
3. **Data Analysis:** Performed sales and profit analysis using Python and SQL.
4. **Data Visualization:** Created charts to identify trends and patterns.
5. **Dashboard Development:** Built an interactive Power BI dashboard.
6. **Business Insights:** Identified key findings and potential business improvements.

## Key Performance Indicators (KPIs)

- Total Revenue: ₹64,511,584.37
- Total Profit: ₹6,285,957.11
- Total Orders: 1,800
- Total Quantity Sold: 7,253
- Average Order Value: ₹35,839.77

## Key Business Insights

- Electronics generated the highest revenue and profit among the product categories.
- Cameras was the highest-performing subcategory.
- The East region recorded the highest performance.
- The Consumer segment contributed the highest sales.
- Standard shipping generated the highest revenue and profit.
- A 30% discount resulted in a loss of ₹36,153, highlighting the importance of discount management.

## Power BI Dashboard

Dashboard components include:

## How to Run the Project

### Python Analysis

1. Clone the repository.
2. Install the required Python libraries.
3. Navigate to the Python folder.
4. Run the analysis script.

```bash
pip install pandas numpy matplotlib seaborn
python main.py
```

### SQL Analysis

1. Open MySQL Workbench.
2. Import the retail sales dataset into your database.
3. Open the SQL analysis file.
4. Execute the queries to generate business insights.

### Power BI Dashboard

1. Install Microsoft Power BI Desktop.
2. Open the `.pbix` dashboard file.
3. Refresh the dataset if required.
4. Explore the interactive dashboard using filters and slicers.
